Что можно улучшить дальше
Превью видео — показывать обложку, автора и название перед скачиванием.

Тёмная тема — переключатель в углу.

Массовая загрузка — вставить несколько ссылок и скачать всё разом.

Прогресс-бар скачивания — сейчас его нет, потому что /download отдаёт файл одним куском.

VPS — вынести сервер на удалённый хостинг, чтобы работало без компа.

Автозапуск сервера — чтобы не запускать node server.js вручную после каждой перезагрузки.
